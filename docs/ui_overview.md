# UI Overview

## Preview Mode
This mode is best for validating the current cut points in the [Shots Table](shots_table.md)
Simply jump between the cut points with ++page-up++ and ++page-down++ keys and make sure the left preview (previous frame) . 
shows a different shot then the right preview (current frame) 

![Image title](assets/cdui_preview_mode_annotated.png)

## Contact Sheet Mode
The contact sheet mode is best for finding missing cuts by scrolling through the frames of the current shot.
Select the first frame of a new shot and hit ++c++ to cut at this point.
![Image title](assets/cdui_contactsheet_mode_annotated.png)


These are the preferred methods to editing the analysis result as the user can exactly see where cuts happen.
Spike can also be selected and added/removed, but this means the user is not looking at the corresponding frames.
For more details on how to interact with the spikes see [Spike Graph](spike_graph.md)
