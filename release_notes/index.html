    Release Notes

    New Feature Bug Fix Improvements

    v0.4.3 (beta)

    Fixed Hiero plugin (Cut Detector option did not show up in Hiero)

    Fixed data communication with Hiero (the new check flag states made this crash silently)

    v0.4.2 (beta)

    Updated help menu to include link to new website

    New caching system (jpg bytes) to make interaction snappier

    New overlay player to play back the currently selected shot

    New export manager to allow more control over the export process

    Added thumbnail column to table

    Added flag column to table to work with the new export manager

    Added ability to rename custom column headers

    Fixed crash when clicking image during detection

    Misc bug fixes

    Made playhead in spike graph transparent to see result of white/blacklisting the current frame

    Selecting the correct shot after deleting a cut

    Progressbar now allows for cancellation of cut detection and exporting

    Splitter position is now saved between sessions and in session file

    v0.4.1 (beta)

    added clip exporter (Export/Media/Clips).

    This needs ffmpeg installed

    added thumbnail exporter (Export/Media/Thumbnails)

    added Preferences UI to manage custom tesseract and ffmpeg paths

    updated Hiero plugin to save the path to CutDetectorPro in the preferences

    updated pyscenedetect to latest (v0.7.0)

    the path to the clip being analysed is now visible in the window title

    otio and its adapter packages are now an external package (bundled) for increased flexibility

    some cosmetic changes

    fixed timecode values

    fixed stale data when a clip was imported during an ongoing session

    fixed stale data when session was loaded during an ongoing session

    fixed pdf export to make sure there is enough space for all custom columns (OCR data)

    fixed XLS export to include all columns

    fixed illegal reel names for edl export

    various bug fixes

    v0.4.0 (beta)

    the graph map in Contact Sheet mode is now interactive, and can be used to navigate the frames

    added option to export a report as .xls with thumbnails

    added an option for a custom start timecode

    copy-to-clipboard exporter has been fixed

    exporting otio, xml, aaf and edl now works

    fixed timecode to start at 00:00:00:00 instead of 00:00:00:01

    default tesseract installations are now detected automatically

    misc bug fixes

    context menus have been added to the table and graph to show available options and their hotkeys

    the hotkey to clear drawn frame selections is now the escape key

    the last export location is now remembered (also between sessions)

    OTIO adapters are now included as source so they can be updated without needing an app update
